# backend-learning

This is where I practice backend development with Node.js and Express. Each folder covers something different  auth, sessions, cookies, validation, error handling, MongoDB, Prisma, file uploads, sending emails, and connecting a frontend to a backend. Nothing here is one big app; they're separate exercises I built while learning.

To run any of them, go into the folder and do `npm install` then `npm start`. More folders get added as I learn new things.
